# 🪔 Ganeshotsav — Celebrating the Spirit of Ganesh Chaturthi

A simple, interactive single-page website celebrating the beauty, traditions, and spirit of Ganesh Chaturthi (Ganeshotsav).

## ✨ Features

- 🕉️ Ganeshotsav-themed design
- 🌱 Eco Score to promote eco-friendly celebrations
- 🪔 Interactive Diya
- 📜 Ganeshotsav traditions and their significance
- 📱 Responsive design
- ⚡ Interactive elements and animations
- 🎨 Single-page experience

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 🌿 Our Message

Ganeshotsav is more than a celebration — it is a time for faith, togetherness, culture, and responsibility.

This project encourages celebrating the festival while being mindful of our environment and preserving the traditions that make Ganeshotsav special.

> Celebrate with devotion. Celebrate with responsibility. 🪔🌱
